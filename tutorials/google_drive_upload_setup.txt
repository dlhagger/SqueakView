SqueakView Manual Google Drive Copy Setup
=========================================

Purpose
-------
This guide explains how to manually copy completed local SqueakView runs to Google Drive using `rclone`.

Current SqueakView behavior
---------------------------
The SqueakView GUI saves runs locally and does not start cloud uploads. A run is complete when the local run directory contains its `run_status.json`, `run_manifest.json`, CSV outputs, video segments, and optional `analysis/` outputs.

If you want an off-machine copy, run `rclone` manually after the run finalizes.

Important:
- manual copies are a copy, not a move
- local run data remains on the Jetson
- include or exclude video files intentionally for your storage budget


Prerequisites
-------------
Make sure `rclone` is installed:

  rclone version

If that command fails, install `rclone` first.


Step 1: Configure a Google Drive remote
---------------------------------------
Run:

  rclone config

Create a new remote with this exact name:

  gdrive

Recommended answers:
- `n` for new remote
- name: `gdrive`
- storage type: `drive`
- client_id: press Enter unless you intentionally use your own OAuth app
- client_secret: press Enter unless you intentionally use your own OAuth app
- scope: choose full access if you want normal upload behavior
- root_folder_id: press Enter
- service_account_file: press Enter
- advanced config: `n`
- auto config: `y` if browser auth works on this machine

After authentication, confirm the remote and quit config.


Step 2: Verify the remote
-------------------------
List the top level of the drive:

  rclone lsd gdrive:

If this works, authentication is valid.


Step 3: Create an upload folder
-------------------------------
Create a folder for copied SqueakView runs:

  rclone mkdir "gdrive:SqueakViewUploads"

You only need to do this once.


Step 4: Manual smoke test
-------------------------
Test with an existing run directory:

  rclone copy "<repo>/runs/<run_dir_name>" \
    "gdrive:SqueakViewUploads/<run_dir_name>" \
    --exclude "*.mp4" \
    --exclude "*.svo" \
    --exclude "*.svo2" \
    --progress

Then verify:

  rclone ls "gdrive:SqueakViewUploads/<run_dir_name>"


Manual copy assumptions
-----------------------
The examples in this file assume:

- remote name: `gdrive`
- destination folder: `SqueakViewUploads`

If manual copies fail, first verify these:

  rclone lsd gdrive:
  rclone lsd "gdrive:SqueakViewUploads"


Changing Google accounts
------------------------
If you want to use a different Google account, reconfigure the remote:

  rclone config

Then either:
- edit remote `gdrive`, or
- delete and recreate remote `gdrive`

The manual commands in this file assume the remote is still named `gdrive`.


Common failure modes
--------------------
1. `rclone: command not found`
- install `rclone`

2. `didn't find section in config file`
- the `gdrive` remote is not configured yet

3. `directory not found`
- create `gdrive:SqueakViewUploads` with `rclone mkdir`

4. auth/browser issues
- rerun `rclone config`
- reauthenticate the `gdrive` remote

5. Manual copy fails
- confirm the source run directory exists and has finalized
- confirm the remote name is still `gdrive`


Useful commands
---------------
Check configured remotes:

  rclone listremotes

Inspect Google Drive root:

  rclone lsd gdrive:

Inspect upload folder:

  rclone lsd "gdrive:SqueakViewUploads"

Manually upload a run:

  rclone copy "<repo>/runs/<run_dir_name>" \
    "gdrive:SqueakViewUploads/<run_dir_name>" \
    --exclude "*.mp4" \
    --exclude "*.svo" \
    --exclude "*.svo2" \
    --progress


Notes
-----
- This setup is independent of FLIR vs ZED capture.
- The GUI is local-only; this document is optional manual offload guidance.
- If the destination folder or remote name changes in your manual commands, update this document too.
