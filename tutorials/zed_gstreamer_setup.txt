SqueakView Tutorial: ZED GStreamer Setup (Jetson)
Date: 2026-02-25

Purpose
- Install ZED GStreamer plugins so SqueakView can use ZED through DeepStream zedsrc/zeddemux.

Prerequisites
- NVIDIA Jetson
- ZED SDK installed
- GStreamer and development packages installed
- Internet access for first git clone

1) Check whether plugins are already available
Run:
  gst-inspect-1.0 zedsrc
  gst-inspect-1.0 zeddemux

If both commands print plugin info, setup is already complete.
If you get "No such element or plugin", continue.

2) Build and install zed-gstreamer
Run:
  cd ~/Desktop
  git clone https://github.com/stereolabs/zed-gstreamer.git
  cd zed-gstreamer
  mkdir -p build
  cd build
  cmake .. -DCMAKE_BUILD_TYPE=Release
  make
  sudo make install
  sudo ldconfig

Notes:
- Root README recommends plain `make` (no `-j`) for safety.
- You may see an ldconfig warning about an NVIDIA library symlink. That is usually unrelated.

3) Verify install
Run:
  gst-inspect-1.0 zedsrc
  gst-inspect-1.0 zeddemux

Expected:
- Both commands return plugin details instead of "No such element".

4) If plugin still not found
A) Clear GStreamer cache and retry:
  rm -f ~/.cache/gstreamer-1.0/registry.*.bin
  gst-inspect-1.0 zedsrc

B) Confirm plugin files exist:
  sudo find /usr /usr/local -type f -name 'libgstzed*.so' 2>/dev/null

Typical install location:
  /usr/lib/aarch64-linux-gnu/gstreamer-1.0/

C) If files exist but inspect still fails, set plugin path:
  export GST_PLUGIN_PATH=/usr/lib/aarch64-linux-gnu/gstreamer-1.0:$GST_PLUGIN_PATH
  gst-inspect-1.0 zedsrc

To persist path across terminals (if needed):
  echo 'export GST_PLUGIN_PATH=/usr/lib/aarch64-linux-gnu/gstreamer-1.0:$GST_PLUGIN_PATH' >> ~/.bashrc
  source ~/.bashrc

5) Validate in SqueakView
- Open SqueakView.
- Configure backend as ZED (DeepStream zedsrc).
- Run preflight.
- Start a run.

Expected:
- No "no element zedsrc" errors.

6) Common issue: batch size mismatch
For current SqueakView behavior:
- ZED + depth OFF + inference ON + stereo left/right -> use DS config batch-size=2
- ZED + depth ON + inference ON -> use DS config batch-size=1

7) Optional RTSP package note
If CMake says RTSP server package missing:
  sudo apt install -y libgstrtspserver-1.0-dev
This only affects gst-zed-rtsp-launch, not zedsrc/zeddemux core capture.
